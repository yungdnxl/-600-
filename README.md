# 600 отборных товаров — инфографика для Wildberries

- `photos/` — исходные фото товаров, имя файла = артикул Леманы.
- `prompts/<артикул>.md` — промпт для ChatGPT: контентная воронка на 4 слайда + характеристики.
- `characteristics/<артикул>.md` — характеристики товара от поставщика.
Всё про один товар связано артикулом Леманы в имени файла/папки.
- `infographics/<артикул>/<артикул>_1..4.png` — готовая инфографика (делает ChatGPT).
- `index.csv` — список: артикул, название карточки, фото, промпт, папка.
